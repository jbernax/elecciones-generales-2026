# Elecciones Generales España 2026 — Guía de Programas y Afinidad Ciudadana

Aplicación web neutral para consultar, comparar y contrastar los programas electorales de las 11 candidaturas activas ante las Elecciones Generales de España de 2026 (29N).

- **11 candidaturas en 6 bloques ideológicos**: Cobertura de `Izquierda` (`Frente Amplio`, `Podemos`), `Centro-izquierda` (`PSOE`), `Centro` (`Democracia para el Siglo 21`), `Centro-derecha` (`PP`), `Derecha` (`VOX`, `SALF`, `FE de las JONS`) y `Otros` (`PACMA`, `Iustitia Europa`, `FO`).
- **Cuestionario de medidas concretas**: En lugar de preguntas abiertas de «acuerdo o desacuerdo», cada cuestión plantea un problema público real con 4 o 5 opciones programáticas concretas y excluyentes, más ponderación de importancia por tema (`Alta (x2)`, `Normal (x1)`, `Baja (x0,5)` u `Omitir`).
